# 下一轮现场日任务书（第 5 次现场）

本文是**任务书**，不是通用手册：只写这一轮现场做什么、按什么顺序做、某一项不过怎么办。跑法、命令块、CSV 列义与判据数值表的原文都在各子文档里，本文只给指针与「判据是什么」的一句话摘要，不复制细节。

读者是这次去现场的人。行前先过 §5 的前置清单，到场照 §4 的执行顺序走。

**不确定性标注**：本文引用的三节跑法（`50-experiments.md` §10.6、§10.7、§10.8）都还是预写、未真机执行；本文的判据摘要同样未经现场校验，第一次执行后按实际回写。

## 1 一句话目标

完成笛卡尔控制层的三项真机验证——T1 `signs`/`zeros` 标定（关节角与电机刻度之间的两个映射参数：`sign` 管方向、`zero` 管零位偏置）、T2 Gate D（运行时门禁之一：首帧观测里该关节的基线实测值缺失或非有限就拒绝，不发命令）、T3 `move_to`（库的笛卡尔入口：给末端一个目标位姿，由 IK 逆运动学解成六个关节角再下发）加卷尺实测——让「Python 库按笛卡尔目标控制手臂到指定坐标」这条链拿到数字背书。

三项不是一条依赖链上的三站：只有 T1 是 T3 的硬前置（T1 产出 T3 要的两份标定文件）；T2 与 T3 之间**没有依赖**——Gate A–F 在 `move_to` 路径上不生效，两者只是共用同一次起 Host 的窗口，收尾同一次断电。

### 3.4 T3 §10.7 `move_to` + 卷尺

**预期剧本，开跑前先读这一段。** `move_to` 下发的是 identity 姿态（单位矩阵，不是「保持当前姿态」），末端姿态会朝 identity 大幅转。identity 形态下 `wrist_roll` 要一路转到约 `-163.7°`；这个跨度 `153.6°` 的起点是**假设 seed `−10°`**，`50-experiments.md` §10.7「点位从哪来」表写明「这是假设，不是真机位姿」。**两支都要按预期留痕，都不是故障**：

- 若真机位姿接近该 seed：跨 `153.6°` 这种量级的单周期解会被 step gate（每周期允许的关节步长上限，`2.0°` / 周期）逐周期拒发，最后走满超时抛 `MotionTimeout`（退出码 `11`，`moves` 里没有成功行）。
- 若真机 `wrist_roll` 本来就在 `-163°` 附近：第一次真跑**可能真的动起来**。

两支的留痕口径同源（`50-experiments.md` §10.7 末尾「现场最可能的形态」段）：按预期形态留痕，不翻修代码、不改限值。

| 项 | 内容 |
| --- | --- |
| 目的 | 笛卡尔入口的第一条真机记录：① IK 解出的关节目标真的下发，② `move_to` 的成功与失败两条路径各留一条现场记录；若出现成功行，就地卷尺量一次 |
| 前置 | ① T1 产出的 `--signs-json` / `--zeros-json`（右臂用右臂自己的文件）；② 先跑 ①a 只读取限窗口，确认 `wrist_roll` 覆盖所需角度；③ 手臂低位或有承托；④ 能按断电开关的人在机器人旁；⑤ 卷尺 ＋ 美纹纸 ＋ 垂线或角尺在场；⑥ 空场、无负载、另一臂不参与；⑦ ①a（只读）与 ①b（离线 dry-run）两者都过再谈真跑（⑥⑦ 出自 `50-experiments.md` §10.7「安全前置」） |
| 做法 | 指针：`50-experiments.md` §10.7。一句话：①a 只读取限窗口 → ①b 离线 dry-run（零网络、零发送）→ ② 9 cm 单次 →（出现成功行才）③ 7 点路径 → ④ 卷尺实测（**必做**，不因 ② 跑顺就跳过；③ 只跑路径不量） |
| 判据 | 出现成功行：就地卷尺实测，实测与 `90 mm` 之差的绝对值 ≤ 1 mm 为过。量的是末端夹爪尖沿基座系 `+Z` 的位移标量，起点必须在跑 ② 之前立成实物标记；读数 1 mm，重复 3 次取中位 |
| 不过怎么办 | 差值超 1 mm：**停在 ④**，不改容差、不改判据，并触发 `docs/ADR.md` D21 的重新评估条件①（卷尺实测偏差超毫米级）。量具不在场：记「未测」，**不得**用目测或 FK 预测值回填。② 落成「超时 + `moves` 无成功行」时**没有位移可量**：记「未测：② 未达成动作，原因「异常类名」」，**不得**用 FK 预测值回填（`50-experiments.md` §10.7 卷尺表「不能量的时候」行） |

判据只比「实测 vs 指令」，判据形式写作 `|实测 − 90 mm| ≤ 1 mm`；JSON 里同一份 URDF 算出的残差只用来解释差值落在哪，不是独立证据。口径与 `docs/ADR.md` D21 决定 2 不同，两处不要混读：D21 写「实测 vs **FK 预测**之差毫米级以内」，本节按 `50-experiments.md` §10.7 ④ 判「实测 vs **指令 `90 mm`** ≤ 1 mm」；D21 那句只作为「几何验收的收口方式与重新评估条件」的出处。
