# 下一轮现场日任务书（第 5 次现场）

本文是**任务书**，不是通用手册：只写这一轮现场做什么、按什么顺序做、某一项不过怎么办。跑法、命令块、CSV 列义与判据数值表的原文都在各子文档里，本文只给指针与「判据是什么」的一句话摘要，不复制细节。

读者是这次去现场的人。行前先过 §5 的前置清单，到场照 §4 的链条走。

**不确定性标注**：本文引用的三节跑法（`50-experiments.md` §10.6、§10.7、§10.8）都还是预写、未真机执行；本文的判据摘要同样未经现场校验，第一次执行后按实际回写。

## 1 一句话目标

完成笛卡尔控制链的三项真机验证——T1 `signs`/`zeros` 标定（关节角与电机刻度之间的两个映射参数：`sign` 管方向、`zero` 管零位偏置）→ T2 Gate D（运行时门禁之一：首帧观测里该关节的基线实测值缺失或非有限就拒绝，不发命令）→ T3 `move_to`（库的笛卡尔入口：给末端一个目标位姿，由 IK 逆运动学解成六个关节角再下发）加卷尺实测——让「Python 库按笛卡尔目标控制手臂到指定坐标」这条链拿到数字背书。

三项是一条链上的三站，不是三件互不相干的事：T1 产出 T3 的硬前置文件，T2 与 T3 共用同一次起 Host 的窗口，收尾同一次断电。

### 3.4 T3 §10.7 `move_to` + 卷尺

**预期剧本，开跑前先读这一段。** `move_to` 下发的是 identity 姿态（单位矩阵，不是「保持当前姿态」），末端姿态会朝 identity 大幅转。按离线推算，identity 形态下 `wrist_roll` 要一路转到约 `-163.7°`（跨约 `153.6°`），而 step gate（每周期允许的关节步长上限，`2.0°` / 周期）会挡下这种量级的单周期解——所以现场最可能的形态是 `MotionTimeout`、退出码 `11`、`moves` 里没有成功行。**这是预期形态，不是故障**：按预期形态留痕，不翻修代码、不改限值。

| 项 | 内容 |
| --- | --- |
| 目的 | 笛卡尔入口的第一条真机记录：① IK 解出的关节目标真的下发，② `move_to` 的成功与失败两条路径各留一条现场记录；若出现成功行，就地卷尺量一次 |
| 前置 | ① T1 产出的 `--signs-json` / `--zeros-json`（右臂用右臂自己的文件）；② 先跑 ①a 只读取限窗口，确认 `wrist_roll` 覆盖所需角度；③ 手臂低位或有承托；④ 能按断电开关的人在机器人旁；⑤ 卷尺 ＋ 美纹纸 ＋ 垂线或角尺在场 |
| 做法 | 指针：`50-experiments.md` §10.7。一句话：①a 只读取限窗口 → ①b 离线 dry-run（零网络、零发送）→ ② 9 cm 单次 →（出现成功行才）③ 7 点路径 → ④ 卷尺实测（**必做**，不因 ② 跑顺就跳过；③ 只跑路径不量） |
| 判据 | 出现成功行：就地卷尺实测，实测与 `90 mm` 之差的绝对值 ≤ 1 mm 为过。量的是末端夹爪尖沿基座系 `+Z` 的位移标量，起点必须在跑 ② 之前立成实物标记；读数 1 mm，重复 3 次取中位 |
| 不过怎么办 | 差值超 1 mm：**停在 ④**，不改容差、不改判据，并触发 `docs/ADR.md` D21 的重新评估条件①（卷尺实测偏差超毫米级）。量具不在场：记「未测」，**不得**用目测或 FK 预测值回填 |

判据只比「实测 vs 指令」，判据形式写作 `|实测 − 90 mm| ≤ 1 mm`；JSON 里同一份 URDF 算出的残差只用来解释差值落在哪，不是独立证据。
